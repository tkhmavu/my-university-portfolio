### Шаг 1. Создание репозитория на GitHub
1. Зайдите на сайт [GitHub](https://github.com/) и войдите в свой аккаунт.
2. В правом верхнем углу нажмите на значок **`+`** и выберите **New repository**.
3. Введите название репозитория (Repository name).
4. Выберите тип репозитория: *Public* (публичный) или *Private* (приватный).
5. **Важно:** Не выбирайте галочки вроде «Add a README file» или «Add .gitignore», если ваш проект уже создан локально, чтобы избежать конфликтов.
6. Нажмите кнопку **Create repository**.

### Шаг 2. Инициализация и отправка проекта из вашего терминала
Откройте терминал в папке с вашим проектом и выполните следующие команды по очереди:

1. Инициализация локального репозитория (если это еще не было сделано):
   ```bash
   git init
   ```

2. Добавление всех файлов проекта в индекс для коммита:
   ```bash
   git add .
   ```

3. Создание коммита с описанием:
   ```bash
   git commit -m "Первый коммит"
   ```

4. Привязка вашего локального репозитория к удаленному (скопируйте ссылку с GitHub, она будет выглядеть примерно так: `https://github.com/имя_пользователя/имя_репозитория.git`):
   ```bash
   git remote add origin ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ
   ```

5. Переименование текущей ветки в `main` (если требуется):
   ```bash
   git branch -M main
   ```

6. Отправка кода в удаленный репозиторий (команда `git push`):
   ```bash
   git push -u origin main
   ```
