# Python Game Portfolio

This repository contains two classic games built using Python and the `Pygame` library:

1. **Tic-Tac-Toe** (`tic_tac_toe.py`)
2. **Snake** (`snake_game.py`)

---

## 📋 Requirements

To run these games, you need to have Python installed on your system, along with the `Pygame` library:
pip install pygame in your Windows/Linux/MacOS terminal.
